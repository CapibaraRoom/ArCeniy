# Адаптация **pacman**

Для адаптации работы пакетного менеджера **pacman** вносятся правки:
- В загрузке системы необходимо указать опцию ```lsm=landlock,```. Она включает использование **landlock** для системы, что необходимо для работы песочницы **pacman**.
- В ```/etc/pacman.conf``` необходимо закомментировать опцию ```DownloadUser = alpm``` для решения проблемы с правами. После этого скачивание пакетов будет проходить от пользователя **root**.
