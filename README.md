АрСений - модульная система на базе Porteus+Arch с простой установкой. Для тех, кому нужна стабильность, настоятельно рекомендуется рассмотреть официальные дистрибутивы [Porteus](https://forum.porteus.org/). В данном проекте целью стоит запуск стороннего образа системы ради расширения используемых концепций и инструментов. Рассчитан на тех, кто хочет простой работы с арчем, кстати.

Во время запуска АрСений выгружает в RAM файловую систему из iso дистрибутива, а так же накладывает на неё фрагменты, оставленные в модулях xzm. Раздел home/ монтируется без выгрузки. Такой подход позволяет поддерживать систему в чистом и безопасном состоянии.

## Целевая структура

```
partition-1/                               -- загрузочный раздел
└── grub/                                  -- система загрузки
    ├── -> partition-3/home/               -- (опционально) ссылка на раздел с home-директорией
    └── -> partition-2/filesystem/iso/     -- ссылка на систему запуска из iso (опционально - ссылка на раздел boot/ )
        ├── vmlinuz
        └── initrd.xz

partition-2/          -- раздел с файловой системой
└── filesystem/       -- директория файловой системы (или корень раздела)
    ├── boot/         -- (опционально) ядро с поддержкой aufs и initrd для запуска
    ├── iso/          -- нераспакованый iso-образ (ФС дистрибутива)
    ├── kernel/       -- модули ядра (дополнения, а не элементы запуска)
    ├── modules/      -- модули для дополнения системы
    └── sigfile       -- (опционально) файл для определения точки загрузки

partition-3/          -- раздел с пользовательской директорией
└── home/             -- директория файлов пользователя
```

> * Автор не гарантирует стабильность работы системы до завершения работ (до выхода релиза >1.0.0). В случае возникновения проблем просьба написать о них и надеяться на решение. Приходите со своим авокадо &#x1F951; - я тоже с ним приду &#x1F951;.


## Планируемые изменения

- Изменение системы запуска sysvinit -> grub (такой подход позволить запускать даже нераспакованые системы).
- Пересборка ядра vmlinuz (необходимо добавить некоторые патчи для корректной работы arch-дистрибутива, т.к. изначально porteus базируется на slackware)
- Изменение скриптов инициализации системы (есть несогласие с текущим вариантом запуска, взятого из Nemesis.
- Реструктуризация каталогов под формат запуска из iso-образа.
- Разобраться с версией лицензии.
